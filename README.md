Playing this mod requires:
1.	Lovely 	(https://github.com/ethangreen-dev/lovely-injector)
2. 	SMODS 	(https://github.com/Steamodded/smods)

For a guide on setting up modded Balatro, I recommend this video:
https://www.youtube.com/watch?v=uDfxnwHO134

Please then take the "Johnny's Pack" folder and move it into your mod directory (not the folder containing this README)

Friendly reminder to be careful to not mess up your main save file, I recommend making a new file and turning on unlock all.

Many thanks to the Balatro discord for being an open and helpful resource for learning to mod, and special thanks to Balatro Vanilla Remade for also being a very helpful reference.

Thank you and have fun playing!
